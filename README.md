📝 App Description

SafeGuard is an Android-based personal safety and emergency response application built for women, university students, and solo travellers in Pakistan. The app allows users to instantly send SOS alerts with their live GPS location to trusted contacts, access Pakistan-specific emergency services, record audio discreetly, simulate fake calls, and get AI-powered safety guidance — all from a single platform.

  ✨ Features
  
- 🆘  SOS Alert  — One tap sends emergency SMS with Google Maps location to all trusted contacts
- 📍  Location Sharing  — Real-time GPS location shareable via SMS
- 📞  Fake Call  — Simulate an incoming call to escape unsafe situations
- 🎙️  Audio Recording  — Background audio recording saved locally on device
- 🤖  AI Safety Assistant — Chat-based assistant for emergency guidance
- 🚨  Emergency Services  — Direct call to Police (15), Ambulance (1122), Highway Police (124), Rescue (1122)
- 🚗 Smart Ride Sharing — Log driver name, vehicle number, and destination before a ride
- 📢 Community Alert — Broadcast safety messages to your trusted network
- 👤 **User Profile** — Store personal, medical, address, and profession details
- 🔒 **PIN Authentication** — 4-digit PIN
