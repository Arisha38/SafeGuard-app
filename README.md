 SafeGuard 🛡️
 A personal safety Android application designed for women, students, and solo travellers in Pakistan.

**About the App**

SafeGuard is an Android-based personal safety and emergency response application built specifically for women, university students, and solo travellers in Pakistan. The app addresses the growing need for a reliable, instant safety tool that works even in stressful situations. With a single tap, users can send SOS alerts along with their live GPS location to trusted contacts, directly call emergency services, record audio discreetly, simulate fake calls to escape unsafe situations, and receive AI-powered safety guidance — all from one platform.

## Features

- 🆘 **SOS Alert** — One tap sends emergency SMS with Google Maps location to all trusted contacts
- 📍 **Location Sharing** — Real-time GPS location shareable via SMS
- 📞 **Fake Call** — Simulate an incoming call to escape unsafe situations
- 🎙️ **Audio Recording** — Background audio recording saved locally on device
- 🤖 **AI Safety Assistant** — Chat-based assistant for emergency guidance
- 🚨 **Emergency Services** — Direct call to Police (15), Ambulance (1122), Highway Police (124), Rescue (1122)
- 🚗 **Smart Ride Sharing** — Log driver name, vehicle number, and destination before a ride
- 📢 **Community Alert** — Broadcast safety messages to your trusted network
- 👤 **User Profile** — Store personal, medical, address, and profession details
- 🔐 **PIN Authentication** — 4-digit PIN for app security

## How to Install the APK

1. Download the APK file from the link above.
2. Transfer the APK to your Android phone (if downloaded on PC).
3. On your phone, go to **Settings → Security → Unknown Sources** and enable it.
4. Open the APK file and tap **Install**.
5. Once installed, open **SafeGuard** and register your account.

---

## How to Run the Project

1. Clone or download this repository.
2. Open the project in **Android Studio**.
3. Sync Gradle files — wait for the build to complete.
4. Connect your Firebase project:
   - Go to Firebase Console → Add Android App
   - Download `google-services.json` and place it in the `app/` folder
5. Enable Firebase Authentication, Realtime Database, and FCM in the Firebase Console.
6. Add your **Google Maps API Key** in `AndroidManifest.xml`.
7. Run the app on an emulator or a physical Android device (API 26+).
